002 : AI Powered Internal Company Docs

This project aims to create a centralized documentation hub for internal company processes, leveraging AI (RAG) to enhance searchability and user experience. It was implemented using Go, Angular, PostgreSQL, Docker, pgvector, OpenAI, Anthropic, Gemini and Ollama APIs. The system ingests various document formats (PDF, Word, Excel, etc.), processes them to extract relevant information, and stores them in a structured database.
